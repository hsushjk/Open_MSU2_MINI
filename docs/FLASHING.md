# 烧录方法

本机没有专用调试口，芯片复位期间由 ROM 决定从 USB 进入 ISP。因此烧录只依赖 USB 线与两个焊盘，不需要额外工具。

## 需要的东西

- Windows 主机一台；
- WCH 官方烧录工具 WCHISPStudio（选中 `CH32X033` 系列）；
- USB A 型延长线或直接插入主机 USB 口；
- 一根镊子或杜邦线，用于上电瞬间短接 ISP 焊盘。

## ISP 焊盘

板上有一对裸露焊盘，标注为 `USB_D+` 与 `3.3V`。两者在上电瞬间短接，ROM 便停在 USB 引导状态；松手后即进入正常固件。

短接的方式是**先按住短接，再插 USB**，识别到设备后立刻松开。不要把它做成常接：MCU 运行起来后会用推挽方式驱动 D+，与 3.3 V 直接对顶。

## 步骤

1. 打开 WCHISPStudio，选择芯片型号 `CH32X033`（与 CH32X035 同系列，工具里若只列出 CH32X035 亦可选）。
2. 用镊子短接两个 ISP 焊盘，同时把模块插入 USB 口。
3. 工具应识别到 `1a86:xxxx` 引导设备，芯片信息栏显示 flash 容量 64 KB。
4. 松开镊子。此时设备停在引导程序里，不会运行原有固件。
5. 选择 `.hex` 或 `.bin` 文件，起始地址填 `0x0000`，勾选"校验"后执行下载。
6. 下载完成后拔插一次 USB，新固件开始运行。

## 固件格式

- Intel HEX：工具直接读，地址已包含在记录里，无需填写起始地址。
- 裸 BIN：从 `0x0000` 起烧写。若文件小于 64 KB，多余区域保持原状或按工具选项擦除，两种都可行。

本项目在验证反编译结论时生成过一份测试彩条固件（1 522 条记录，覆盖 `0x0000`–`0x6110`），按上述流程刷入后开机显示 8 色竖条，可用于确认烧录链路完好。该固件不属于本仓库交付内容，需要时可按反编译仓库的方法自行生成。

## 注意事项

- **背光直接接 5 V**，没有限流开关。第一次上电前建议串一个电流表，确认背光电流在屏厂规格内（R1 只有 5.1 Ω，实际几乎全靠屏内阻）。
- **不要常接 ISP 焊盘**，理由见上文。
- 烧写过程中不要拔线。CH32 系列在擦写时掉电可能使芯片停在半写状态，重新进入 ISP 即可恢复，但需要重新完整烧写。
- 若工具始终识别不到设备，依次检查：USB 口是否为数据口、短接是否在插线瞬间完成、焊盘是否被阻焊覆盖、芯片是否已经损坏（D+ 对地短路等）。

## 恢复原厂固件

本仓库不提供原厂固件。若需要恢复到出厂状态，请从模块供应商处获取 `[固件]MSU2_MINI_Firmware_V1.1.hex` 并按其说明烧写；烧写后可用反编译仓库中的 `tools/hex2bin.js` 核对镜像指纹是否与 V1.1 一致。
