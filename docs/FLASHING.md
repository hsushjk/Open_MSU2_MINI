# MSU2_MINI 刷写说明

板子没有调试口、没有复位键、没有 BOOT 键。刷固件只有两条路：

| 路线 | 什么时候用 | 需要什么 |
| --- | --- | --- |
| **A. USB ROM ISP** | 第一次烧、救砖、固件已经跑飞 | USB 数据线 + 镊子（短接两个焊盘）+ WCHISPTool |
| **B. OTA（免拆升级）** | 设备上已运行可用的 1.0.9 固件 | 上位机 `Open_MSU2_MINI_Console`，页面或命令行操作 |

## 1. ISP 救砖焊盘

板上有一对焊盘：`USB_D+` 与 `3.3V`。

```text
短接这两个焊盘 → 同时插入 USB → ROM 引导程序接管 → 松开
```

- 必须在插线的瞬间短接；芯片已经开始跑用户代码后再短接无效。
- 不可常接：固件跑起来后用推挽驱动 D+，与 3.3 V 对顶会拉低电源。
- 焊盘被阻焊层盖住时，用针尖轻刮一下再短接。

## 2. 路线 A：USB ROM ISP

### 准备

| 项 | 说明 |
| --- | --- |
| 工具 | WCHISPTool（在 wch.cn 搜索下载） |
| 线材 | 能传数据的 USB 线；板边金手指直接插 USB-A，建议加延长线方便按压焊盘 |
| 固件 | `Open_MSU2_MINI_FW/build/msu2_proto_fw.hex`（推荐）或 `.bin` |

### 步骤

1. 打开 WCHISPStudio，芯片族选 **CH32X033**（列表中的 CH32X035 同族项也可用）。
2. 用镊子按住 `USB_D+` 与 `3.3V` 两个焊盘，保持短接的同时把板子插进 USB。
3. 工具出现引导设备（USB ID `1a86:xxxx`）、读出芯片标称容量 64 KB 后，松开镊子。
4. 选固件文件：HEX 的地址在记录里，起始地址留 `0x0000`；裸 BIN 从 `0x0000` 起烧。
5. 勾选校验，点下载，等进度走完。
6. 拔插一次 USB，设备应重新枚举为 `1A86:FE0D`。

烧写地址从 `0x0000` 起：固件运行在 `0x00000000` 映射，内部 flash 编程由固件走 `0x08000000` 别名，两者指同一块存储。

### 如果识别不到

| 现象 | 检查 |
| --- | --- |
| 工具里没有引导设备 | 短接是否发生在插线瞬间；换数据线；确认插的是 USB-A 数据口（不是充电头） |
| 设备出现但报容量为 0 / 通信失败 | 焊盘是否被阻焊盖住、接触是否稳定；换一根短一点的线 |
| 一直进不去 | 量 `USB_D+` 对地是否短路（芯片可能已损坏） |
| 烧完不启动 | 确认固件版本为 1.0.9 且镜像没有超过应用区上限；重新走 ISP 完整重烧一次 |

## 3. 路线 B：OTA（免拆升级）

### 用上位机页面

1. 运行 `python msu2_mini.py`，打开 `http://127.0.0.1:8765`。
2. 在「固件升级」卡片选 `.hex` 或 `.bin`，点升级。
3. 上位机自动完成：HEX → bin → 写 NOR `0x080000` → 提交 CRC32 → 触发搬运 → 设备复位。

### 用命令行

```powershell
python msu2_mini.py --flash Open_MSU2_MINI_FW/build/msu2_proto_fw.hex
```

### 固件侧发生了什么

| 步 | 命令 | 动作 |
| --- | --- | --- |
| 1 | `0A 12 01 00 len_hi len_lo` | 擦除 NOR 暂存区，登记镜像长度（1–48000 B，256 的整数倍） |
| 2 | `0A 12 02 00 wl_hi wl_lo` + 数据 | 分窗写入，每窗 1–2048 B，收满一窗回一次 `0A 12 06` |
| 3 | `13 00 crc0..crc3` | 校验整段 CRC32（大端），对上才把镜像头标为有效 |
| 4 | `14 00 A5 5A 00 00` | 置“请升级”标志，80 ms 后体检内部 flash 并从 NOR 逐页搬运，成功后复位 |

第 4 步必须同时满足：`b2 == 0xA5 && b3 == 0x5A`、本次上电已成功执行第 3 步、没有进行中的像素流/资产写/签名核对。不满足时回 `14 00 15 FE 00 00`，不会改动内部 flash。

失败原因读 `0A 0F`，或直接看 `14 00 15 <code>` 的 `code`：

| 值 | 含义 | 处理 |
| --- | --- | --- |
| 0 | 成功（随后复位） | — |
| 1 | 镜像头 magic 不是 `MSU2` | 文件损坏，重传 |
| 2 | 长度非法 | 镜像需 ≤48000 B 且补齐为 256 的整数倍 |
| 3 | 内部 flash 体检失败 | 内部 flash 未被改动；改走 ISP 刷 |
| 4 | 搬运后读回校验失败 | 内部 flash 可能半写，走 ISP 重刷 |
| 5 | NOR 整段 CRC 与镜像头不符 | 传输错误，内部 flash 未被改动；重走第 1–3 步 |

OTA 只改内部 flash 的应用区，NOR 里的图像资产与设置不受影响。

## 4. 恢复原厂固件

本仓库不提供原厂固件。需要恢复时向供应商索取原厂镜像，按路线 A 烧回即可。原厂固件枚举为 `1A86:FE0C`，与本固件的 `1A86:FE0D` 可区分。

## 5. 注意事项

- 不要常接 ISP 焊盘，也不要带电短接。
- 擦写过程中不要拔线：CH32 掉电会停在半写状态，重进 ISP 完整重烧即可恢复，不是砖。
- 背光 5 V 直连、R1 只有 5.1 Ω，无限流开关；第一次上电建议串电流表确认没有短路。
- 固件看门狗约 1.6 s。如果烧完 2 秒内自动重启，说明启动过程卡住，读 `0A 0D` 面包屑看停在哪一步。
